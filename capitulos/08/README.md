[← Índice del repositorio](../../README.md) · [Libro gratuito: lectura en línea y PDF versionado](URL_WEB_DEL_LIBRO_PENDIENTE)

## El problema que estudiamos

Una tarea diferida conserva una captura y la utiliza después de que haya terminado el tiempo de vida del objeto original. El problema obliga a examinar qué comunica la interfaz y quién conserva los datos.

Este capítulo del libro explica **resultados y parámetros, recursión, variádicas, `std::move`, `std::forward` y capturas lambda.**. Los archivos de esta carpeta permiten seguir el razonamiento con código real: observar la construcción que plantea la dificultad, estudiar una alternativa y comprobar las hipótesis que hacen válida una solución. La explicación del libro proporciona el contexto necesario para interpretar cada fragmento.

## Qué puedes aprender con este código

Los veinte archivos `E01.cpp` a `E20.cpp` permiten recorrer los conceptos en el orden del capítulo. Identifica en cada uno si el ejemplo describe una llamada inmediata, una transferencia de propiedad o una función que se almacena para ejecutarse después.

La lectura resulta más útil si, antes de consultar la solución, intentas responder a dos preguntas: **¿qué garantiza C++17 en este punto?** y **¿qué propiedad adicional necesitamos justificar para el sistema?** Las respuestas pueden depender de la plataforma, de las condiciones de entrada o de reglas MISRA que se estudian conjuntamente.

## Cómo comprobar los ejemplos

No se distribuyen pruebas ni scripts en esta carpeta. Para verificar la sintaxis de un ejemplo autónomo, utiliza compilación a objeto y revisa antes sus dependencias.

Para un fragmento **autónomo, identificado previamente como seguro y compilable**, una primera comprobación puede ser:

```sh
g++ -std=c++17 -Wall -Wextra -Wpedantic -pedantic-errors -c ejemplos/ARCHIVO.cpp
```

Sustituye `ARCHIVO.cpp` por un nombre existente en `ejemplos/`. Esta orden solo comprueba la traducción del archivo, no su comportamiento durante la ejecución. Para casos con cabeceras, bibliotecas, opciones de preprocesador o varias unidades de traducción, sigue las instrucciones específicas anteriores y el contexto del capítulo. Comprueba también qué compiladores y herramientas están instalados antes de utilizar scripts.

> **Antes de ejecutar:** Una captura explícita de `this` no prolonga la vida del objeto. Evita ejecutar rutas con referencias o capturas colgantes. Los ejemplos intencionadamente incorrectos pueden servir para examinar un diagnóstico o un rechazo del compilador, pero no deben ejecutarse para provocar comportamiento indefinido. Una compilación correcta, una prueba funcional satisfactoria o la ausencia de advertencias no constituyen por sí solas una declaración de conformidad con MISRA C++:2023.
